# 🧠 Mi Wiki de Desarrollo (My Learning Path)

¡Bienvenido a mi repositorio central de estudio! 🚀

Este repositorio funciona como mi **"Segundo Cerebro"** o jardín digital. Aquí documento, organizo y almaceno todo el código, apuntes y proyectos de los cursos que tomo (Platzi, Udemy, Coursera, etc). 

El objetivo es tener un lugar organizado donde pueda consultar rápidamente cómo hacer algo sin tener que buscar en videos antiguos.
